# All About Knowledge
3차 조별과제 프로젝트 : E-learning System 구현하기

## 👨‍🏫 프로젝트 소개
개발자가 되기 위해 필요한 컴퓨터공학 이론과 프로그래밍 언어에 대한 강좌를 서비스하는 웹 사이트 제작.

## ⏲️ 개발 기간
2024.05.20(월) ~

프로젝트 사전 준비 : UseCase, 요구사항명세서, UI설계, ERD 설계


## 💻 개발환경
Version : Java 11

IDE : STS3

DB : Oracle
